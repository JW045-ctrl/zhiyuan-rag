## 变更一：外卖配送移出本期

| 项目 | 记录 |
| --- | --- |
| 变更日期 | 2032年8月24日 |
| 变更状态 | 已批准并生效 |
| 变更前设想 | 同时支持到店自取和外卖配送 |
| 最终决定 | 本期只支持到店自取；外卖配送移出本期；不承诺后续开发日期 |

**变更原因：** 外卖配送还涉及配送范围、配送费用、骑手接口、配送超时、配送状态和售后责任。此次变更用于控制范围并保护2032年10月20日上线目标。

**项目影响：** 缩减本期范围，移除外卖配送及其相关处理；该决定不是对未来外卖功能的承诺。

**工期影响：** 当前资料没有记录该变更导致最终工期延长，正式上线目标保持不变。

## 变更二：增加会员等级进度显示

| 项目 | 记录 |
| --- | --- |
| 变更日期 | 2032年9月7日 |
| 变更状态 | 已批准并生效 |
| 提出方 | 客户营销部门 |
| 变更前设想 | 用户查看当前会员等级 |
| 最终决定 | 增加升级所需积分、当前进度、当前与下一等级权益简要说明 |

**变更原因：** 客户营销部门提出，用户除当前等级外还需要看到升级所需积分、进度及等级权益简要说明。

**项目影响：** 调整会员中心原型和页面，并增加相关显示与测试。

**工期影响：** 该变更不延长项目最终工期。
