## 6. 已知限制

### 文档解析与检索

1. v0.1 使用 Dify 原生 PDF 解析，没有独立的版面恢复、公式识别或 OCR 工作流。
2. 数学公式可能被拆成多个符号或换行，造成子 Chunk 语义过碎。
3. PDF 跨页答案可能分属不同父 Segment；题目、主计算、端点判断或误差上界不能保证一起进入引用。
4. 复杂版式、扫描版、图片公式、双栏和表格资料可能只能在线浏览，无法可靠正文检索。
5. 同一 PDF 中相邻题目和替代解法容易互相竞争；命中文件不代表命中目标题目。
6. 重建 Segment 会改变 Segment ID，历史评估记录不能当作当前引用映射。

### 回答与引用

1. 在证据不完整时，当前模型仍可能明确标注“通用知识”后继续补答；严格模式仍把这种行为判为失败。
2. `calc-answer-007` 和 `calc-answer-010` 会因跨页或相邻解法召回问题错误拒答。
3. 引用卡片真实反映 Dify 返回内容，但“存在引用”不表示引用足以支撑回答全部核心结论。
4. 当前网站没有为引用推测页码、章节或站内链接，也尚未实现 SQLite 资料跳转；这是避免伪造定位信息的有意限制。

### v0.1 产品与发布边界

1. 目前只覆盖大一微积分的有限资料和少量章节，不代表整门课程知识。
2. 不支持登录、聊天历史、用户上传、OCR或图片提问。
3. 当前仍是本地演示配置；公开部署前仍需完成域名、HTTPS、服务端密钥、匿名频率限制、日志与隐私策略检查。
4. 评估集当前只有15道启用题；剩余15道仍需在资料和人工参考答案确认后启用。
