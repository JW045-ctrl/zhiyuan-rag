## 密钥边界

- `DIFY_API_KEY` 只允许存在于 `.env.local` 或部署平台的服务端 Secret 中。
- 禁止使用 `NEXT_PUBLIC_DIFY_API_KEY` 或把 Dify 基础地址/API Key 返回给浏览器。
- `.env*` 默认全部忽略，仅允许提交空值示例文件。
- Dify `docker/.env` 与 `.env.backup` 均已加入 Dify 仓库忽略范围，当前都未被跟踪。
- RAG 结果可能包含课程原文片段，默认不进入 Git。
- Dify DSL 导出后必须再次扫描真实 Key、Token 和本机路径。

## 自动指标定义

- 预期资料命中率：具有 `expected_documents` 的已执行 `ANSWER` 题中，至少命中一个预期文件名或文档 ID 的题目比例。
- 正确拒答率：已执行 `REFUSE` 题中，答案命中明确拒答短语的题目比例。此项是透明的规则检测，不等同于最终人工判断。
- 引用存在率：所有已执行 `ANSWER` 题中，至少返回一条真实 `retriever_resources` 且请求无错误的题目比例。
- 平均响应时间：所有实际发出请求的题目从发送到 SSE 结束的平均毫秒数。
