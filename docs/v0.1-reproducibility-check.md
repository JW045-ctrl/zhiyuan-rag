## 结论与边界

本次证明：网站工程可以从公开仓库全新安装、测试、构建，并在提供有效服务端配置后连接现有 Dify。

本次没有重新导入课程PDF，也没有从空白 Dify 实例重新创建模型配置、知识库和索引。因此它没有证明“仅靠GitHub仓库即可恢复完整课程知识库”。课程资料、模型供应商凭据、Dify数据库、知识库索引和应用API Key均不包含在公开仓库中；新用户需要使用自己有权使用的资料完成这些外部准备工作。

- README 原安装目录仍写作旧名称，已改为公开仓库目录 `zhiyuan-rag`；
